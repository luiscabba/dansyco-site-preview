# Dansyco Shipyard website preview

Pre-discovery mockup of a new website for Dansyco Marine Works & Shipbuilding Corp., built from public sources for review. Not the official site.

- `index.html` home page, `vessels/` one page per vessel type
- Static files, no build step. Deployed on Vercel.
- Photos are AI-enhanced previews of Dansyco's own images and will be replaced with originals.
